## Installation

Download the installer or archive from the [Releases page](https://github.com/nsis-community/plugin-inetbgdl/releases).

If you downloaded the zip archive, extract it into your NSIS folder: it adds `InetBgDL.dll` to `Plugins/<variant>/`.
